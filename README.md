📺 YouTube Analytics Dashboard

A modern and interactive dashboard built using **Streamlit** and **YouTube Data API v3** to analyze and visualize YouTube channel performance in real time.

🚀 Features

* Real-Time YouTube Data API Integration
* Live Subscriber Count
* Live View Count
* Total Video Analysis
* Top Performing Videos Ranking
* Engagement Score Analysis
* Interactive Bar Chart
* Donut Chart for View Distribution
* Subscriber Growth Trend Visualization
* Dynamic Video Filtering
* CSV Report Download
* Professional Dashboard UI

📊 Analytics Included

* Subscriber Analysis
* Views Analysis
* Video Performance Analysis
* Engagement Metrics
* Top Videos Comparison
* Trend Visualization

🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* Plotly
* YouTube Data API v3
